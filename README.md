# Ammar's portfolio

A static website ready for GitHub Pages. No build tools or dependencies are required.

- `index.html` contains the page content, grouped by section comments.
- `styles.css` contains shared styles and font declarations; some section styling remains in the HTML.
- `assets/fonts/` contains the local fonts.

Open `index.html` in a browser to preview. Publish the repository using GitHub Pages from the root of the chosen branch. Asset paths are relative and work on a project site.

The demo is a placeholder to update when ready. Contact details include email and LinkedIn; WhatsApp can be added when the number is available. The headshot is at `assets/headshot.jpeg`. Three case studies link to PDFs in `assets/caseStudies/`.

To add a case study, place its PDF in `assets/caseStudies/`, copy an existing slide in the Case study carousel in `index.html` and add a navigation link, and update the title, description, and PDF path. The download link works with relative paths on GitHub Pages.
